# Security policy

## Reporting a vulnerability

Do not include credentials, personal data, production payloads, or private endpoint URLs in a public issue.

Use the support contact at [Blaz Algo Systems](https://blazalgosystems.netlify.app/contact/) and provide a minimal synthetic reproduction. Reports should identify the affected version, expected behavior, observed behavior, and any relevant traceback with secrets removed.

## Scope

This package is a provider-neutral reliability engine and deterministic demonstration. It does not make network requests, manage credentials, or claim to secure a production system.
